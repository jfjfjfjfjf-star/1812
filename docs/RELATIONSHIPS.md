# Система отношений: устройство и первая глава

Собрано 31.10.2026 по ТЗ «Система отношений» и сюжетному контексту, присланным Кириллу в проект. **Всё содержимое — черновик:** реплики, числа и имена Татьяны и других новых людей утверждает Кирилл. Сюжет, даты и утверждённые диалоги недели торговли не менялись. Предложения помечены словом «предложено».

### Состояние

```
state.relationships = {
  schemaVersion: 1,
  bonds: { andrey_tatiana: { trust, closeness, tension, status, memories: { id: { day, ev } }, conflicts: { id: { stage, day, log } } }, andrey_mother: {…} },
  appliedEvents: { eventId: { day } },
  seenScenes: { sceneId: { day } }
}
```

`andrey_tatiana` — отношение **Татьяны к Андрею**. Старт Татьяны: доверие 40, близость 25, напряжение 0, статус «знакомые». Старт матери: 60 / 70 / 10, статус «семья». Все числа — рабочие, не утверждённый баланс.

Память хранит только то, что человек видел и слышал. Ответ Сорокина про рубахи Андрей узнаёт сам (запись в `state.heard`), а Татьяна узнаёт его, только когда Андрей ей расскажет (событие `ch1_jun07_tatiana_kept`).

### Как писать реплику с последствием

```js
{ text: '…', goto: 'tat5_small', promise: 'ask_sorokin_shirts', rel: 'ch1_jun05_tatiana_small_promise' }
```

`rel` — id или список id из `REL_EVENTS`; `promise` / `keep` / `breakPromise` — обещание; `scene` — сцена пройдена, гость уходит. Условие: `need: { relationship: { id: 'andrey_tatiana', trustMin: 35, tensionMax: 60 } }` или `need: { story: 'имя' }` (имена в `STORY_NEEDS`). Подробный список ключей — в комментарии над `needFails` в `index.html`.

Правила, которые держит код:

- Порядок в `act`: сначала ресурсы (монеты, `pay`), потом обещание, потом отношения, потом сохранение. Отказ по ресурсам ничего не меняет.
- Событие с тем же id повторно ничего не даёт (повторный разговор, загрузка, перерисовка).
- Статус связи меняет только событие с полем `status`. Числа порогов статус не трогают; в первой главе ни одно событие статус не меняет.
- Каждую ночь мелкое напряжение (не выше `calm.below`) уменьшается на `calm.step`, но не при открытом, признанном или исправляемом конфликте. Память и конфликты сами не стираются.
- Пропущенная встреча (Андрей был в лабазе или трактире) числа не меняет: сцена просто не проходится.
- Мать не связана с торговой репутацией: разговоры с ней не меняют деньги, товар, сделки и слухи (проверено тестом).
- Выход из пожара от отношений не зависит: сцена пожара не читает `state.relationships`.

## 2. Миграция сохранения

Ключ сохранения прежний (`letopisi1812_save_v7`). `load()` вызывает `migrateRelations`: недостающие связи добавляются со стартовыми числами, **без** событий и воспоминаний (мы не знаем, что игрок говорил раньше); числа приводятся к 0–100; неизвестные события, воспоминания и конфликты отбрасываются; прогресс лавки не трогается. Версия данных `DATA_VERSION` 24 стоит в `data.js` и в проверке `index.html`.

## 5. Один цикл Андрей — Татьяна

Разговор → обещание → действие → следующая встреча. Все три вечерние сцены **дополнительные**: игрок может не прийти, торговая неделя от них не зависит.

| День | Сцена | Условие | Выбор Андрея | Последствие |
|---|---|---|---|---|
| 3 июня, вечер | `tat_jun3`: Татьяна заходит «за нитками» | вечер, лавка закрыта | слушать про шитьё / пошутить / отложить | «слушать»: близость +4 и память о шитье; шутка: +2; «не надорвись»: напряжение +2; «отложить»: ничего (причина названа) |
| 5 июня, вечер | `tat_jun5`: просит помочь найти заказчиков | вечер; текст зависит от того, слушал ли Андрей 3 июня | а) спросить у Сорокина и только, б) выхлопотать десять рубах, в) не обещать | а): обещание `ask_sorokin_shirts` до пятницы; б): `get_sorokin_order`, близость +2, напряжение +4, конфликт «решил за неё» открыт; в): доверие +2. Правильного ответа нет |
| 5–7 июня | Сорокин в лабазе | обещание открыто | спросить про рубахи | а) выполнено; б) Сорокин «десятка не жди», обещание не выполнено; ответ записан как сведение |
| 7 июня, вечер | `tat_jun7`: разговор после закрытия | вечер | зависит от сделанного | см. ниже |

Варианты 7 июня (первый подходящий):

1. Спросил Сорокина и обещал только это: рассказать ей (доверие +6, близость +3, напряжение −2) или отложить.
2. Обещал десять рубах и был у Сорокина: сказать правду (доверие −3, напряжение −3, конфликт «признан»; можно предложить сам показать образец: конфликт «исправляется», новое обещание `bring_sample`) или уклониться (доверие −6, напряжение +6, конфликт остаётся открытым, близость сохраняется).
3. Обещание не выполнено: отговорка (доверие −4, напряжение +3, конфликт открыт) или извинение (доверие −4, напряжение +1, конфликт «признан»). Извинение факта не стирает.
4. Не обещал, но слушал 3 июня: короткий тёплый разговор (близость +3). 5. Иначе: короткая холодная встреча.

Перенос в главу 2: открытые обещания, конфликты и память сохраняются; конфликты «признан» и «исправляется» ждут действий. Статус «знакомые» не меняется: интерес и сближение — сюжетные сцены следующих глав.

## 6. Эпизод с матерью (6–7 июня)

6 июня утром на заставке: «Мать с утра сидит над какой-то тетрадью». Мать просит закупить крупу впрок на все деньги. Выбор:

- «Я сам спрашивал Сорокина, цена прежняя» (только если Андрей проверил слух): доверие +4, напряжение −2. Мать согласна, но просит следить за мешками.
- «Давай сначала спрошу» (если не проверил): без чисел.
- «Я хозяин, решаю я»: напряжение +8, доверие −3, конфликт открыт. 7 июня мать холоднее; извинение переводит конфликт в «признан», а объяснение матери (голодный год при отце — **предложено**, биография матери не утверждена) и «решать вместе» закрывают его.
- «Как скажешь»: близость +2, без конфликта.

На торговлю, деньги и товар разговор не влияет.

## 8. Заметки «Люди» и отладка

В заметках (клавиша N) под заголовком «Люди» — только то, что знает Андрей: кто это, воспоминания с заметками, обещания связи и нерешённые ссоры. Чисел и «правильных ответов» нет. Связь появляется после первого события.

Отладочная панель (`index.html?debug=1`, клавиша `` ` ``): параметры, воспоминания, конфликты и стадии, события, обещания, пройденные сцены, гости в месте, а для открытой реплики — почему каждый вариант доступен или скрыт. Кнопки загружают воспроизводимые состояния: «Сближение», «Обида», «Признанная ошибка», «Исправление», «Близость при ссоре» (`DEBUG_STATES` в `data.js`).
