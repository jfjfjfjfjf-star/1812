# Требования к изображениям первой сцены (лавка)

Для Кирилла и ChatGPT. Только технические требования, чтобы файлы подключались без доработок кода. Стиль определяет утверждённый референс (Yes, Your Grace + Tails Noir, с уклоном в Tails Noir; холодный свет окна, тёплый свет свечи). Макет интерфейса задаёт оформление и расположение; весь текст и кнопки рисует код, в картинки их не вшивать.

Если файл не подходит по имени или размеру, игра его не использует, показывает временную заглушку и в левом верхнем углу пишет «Временная графика». Подробности (какой файл и какого размера) в браузере: F12 → вкладка Console.

## Общие правила

- PNG, 8 бит на канал, RGBA.
- Масштаб 1:1. Игра рисует сцену на сетке 320×180 и увеличивает её на экране только целое число раз без сглаживания. Один пиксель картинки равен одному пикселю сетки.
- Для персонажей и слоёв с прозрачностью: альфа только 0 или 255, без полупрозрачных краёв.
- Имена только латиницей, без пробелов, без «(1)». Регистр важен.
- Тестовые и концептуальные картинки в `assets/` не класть, исходники только в `assets/source/`.

## 2. Прилавок отдельным слоем

| | |
|---|---|
| Файл | `assets/backgrounds/shop_counter.png` |
| Размер | ровно 396×180 с прозрачностью |
| Что внутри | только передняя часть прилавка (область x 135–353, y 95–135) с теми же пикселями, что в `shop.png`; всё остальное прозрачно |

Порядок слоёв: фон → мать → Андрей за прилавком → **этот слой** → покупатель → Андрей при свободной ходьбе → передний план. За прилавком Андрей закрыт им примерно до пояса; покупатель всегда перед прилавком; при свободной ходьбе Андрей идёт перед прилавком. Так как слой дословно повторяет участок фона, при уходе Андрея не остаётся дыр, двойных контуров и повторяющихся предметов.

Если файла нет, а фон есть, игра вырезает тот же участок из фона по прямоугольнику `ART.counterFront.rect`. Если Кирилл перерисует прилавок или фон, слой надо пересобрать (скажите, сделаю).

Ограничение: предметы, стоящие на самом прилавке (весы, счёты, книга, ступка), нарисованы позади Андрея. Часть из них он перекрывает, а настоящая «стойка» их не прикрывает. Если нужна точность, потребуется отдельный слой этих предметов (необязательно, вопрос к Кириллу).

## 3. Передний план: ящики у двери

`assets/backgrounds/shop_front.png`, 396×180 с прозрачностью (альфа 0/255); рисуется поверх всех персонажей. **Подготовлен 21.10.2026** из `shop.png`: внутри силуэта передних ящиков справа (лесенка ящиков с x ≈ 313 и стопка с мешками перед дверью с y ≈ 108) — точная копия пикселей фона, всё остальное прозрачно. Силуэт обведён вручную по контурам ящиков и мешков, **пол и дверь в слой не входят** (это не прямоугольник). Поэтому Андрей и покупатели у двери проходят позади ящиков: видна верхняя часть тела, ноги закрыты ящиками.

Слой собирает `tools/make_shop_front.py` (Python 3 + Pillow; силуэт — список точек в начале файла). Если Кирилл перерисует фон или ящики, силуэт надо обвести заново и пересобрать слой. Если файла нет, игра пишет «Временная графика» и рисует Андрея поверх ящиков.

**Как подготовлен кадр покоя.** Из присланной фигуры (1145×1374, белый фон) фон убран заливкой от краёв, фигура уменьшена без растяжения по отдельным осям: 244×1064 → 16×69 пикселей (рост 69, строки 7–75, столбцы 40–55, центр на границе 47/48), усреднением по площади, края резкие (альфа 0/255), цвета сведены к 24, чтобы пиксели оставались чёткими. Исходник сохранён. Лицо при таком размере занимает около 4×4 пикселей: черты читаются, но мелкие детали потеряны. **Кириллу нужно оценить глазами лицо, волосы и силуэт**; если не устраивает, нужна ручная доработка пикселей или кадр, нарисованный сразу в 96×80.

**Ходьба.** Игра подставляет статичный кадр покоя, когда файла нет. Это временная мера, не анимация: движение выглядит как скольжение. Не собирать ходьбу вращением частей тела; требования к кадрам в `docs/ANIMATION_SPEC.md`. Для настройки нужны: сколько пикселей Андрей проходит за полный цикл из 8 кадров (число для `ANDREY.cycleDistance`, сейчас временно 40) и нужны ли отдельные кадры ходьбы влево.

**Масштаб в игре.** `SCENE.charScale = 1`: персонажи рисуются как нарисованы, пиксель в пиксель (раньше было 1.2, Андрей выходил почти с дверь). Фигуру отдельно по осям не растягиваем.

## 7. Товары на фоне и остаток

Мешки, корзины и банки, нарисованные на фоне, **декоративны** и остаток не показывают: точный остаток виден только в торговой панели и в сводке «В лавке» при пустой очереди. Временные квадратики остатка на прилавке теперь рисуются только пока фон ещё заглушка (`ART.stockMarks.show: 'auto'`), с настоящим фоном они отключены. Фиктивную систему исчезновения нарисованных товаров намеренно не делаем.

## 8. Что закрывает интерфейс (по макету)

Важные детали сцены лучше держать вне этих зон. Значения в долях сетки 320×180.

## 9. Как проверить свои файлы

1. Размеры: правая кнопка по файлу → «Свойства» → «Подробно».
2. Положить в папки распакованной копии (не из архива), открыть `index.html`.
3. Если «Временная графика» исчезла, всё принято. Иначе F12 → Console покажет, какой файл не найден или какого размера он должен быть.
4. Дойти до рабочего места (подсказка «E — Встать за прилавок»), нажать E: Андрей за прилавком, покупатель перед ним, портрет слева.
