# Требования к изображениям первой сцены (лавка)

Для Кирилла и ChatGPT. Здесь только технические требования, чтобы файлы подключались без доработок кода. Стиль и содержание определяет утверждённый Кириллом референс (Yes, Your Grace + Tails Noir, с уклоном в Tails Noir; холодный свет окна, тёплый свет свечи).

Если файл не подходит по имени или размеру, игра его не использует, показывает временную заглушку и в левом верхнем углу пишет «Временная графика». Подробности (какой файл и какого размера) смотреть в браузере: F12 → вкладка Console.

## Общие правила

- Формат: PNG, 8 бит на канал, RGBA.
- Масштаб 1:1. Игра рисует сцену на сетке 320×180 и увеличивает её на экране только целое число раз без сглаживания. Один пиксель картинки равен одному пикселю сетки. Картинки, нарисованные в другом масштабе, не подойдут.
- Границы чёткие: прозрачность только полностью прозрачная или полностью непрозрачная (альфа 0 или 255), без размытия и полупрозрачных краёв.
- Имена только латиницей, без пробелов, без «(1)» в конце. Регистр важен: `shop.png`, а не `Shop.png`.
- Тестовые и концептуальные картинки в `assets/` не класть: там только утверждённые файлы.

## 1. Фон лавки

| | |
|---|---|
| Файл | `assets/backgrounds/shop.png` |
| Размер | ровно 640×180 пикселей |
| Прозрачность | не нужна, картинка полностью непрозрачная |
| Что внутри | помещение лавки целиком: стены, полки, окно, прилавок, пол, свеча; без персонажей и без интерфейса |

Как работает: мир лавки 640 пикселей в ширину, экран показывает окно шириной 320, камера следует за Андреем по горизонтали и упирается в края. То есть фон — это два экрана подряд, левый край картинки совпадает с левым краем лавки.

Когда `shop.png` подключён, игра перестаёт рисовать старые окна, полки, прилавок, свечу и ковёр из цветных прямоугольников.

Координаты мира, под которые собран код (все значения лежат в `data.js`, блок `SCENE`, и могут быть изменены, если композиция потребует):

| Что | Координата |
|---|---|
| Линия пола (ноги персонажей) | y = 151 |
| Андрей в начале игры | x = 60 |
| Мать | x = 120 |
| Покупатель у прилавка | x = 430 |
| Прилавок (зона осмотра товаров) | x от 300 до 630 |
| Границы ходьбы Андрея | x от 16 до 624 |

Что учесть в композиции:
- Персонажи стоят на линии y = 151, ниже неё пол остаётся виден ещё около 29 пикселей.
- Покупатель стоит перед прилавком примерно на x = 430, Андрей подходит к нему слева.
- При открытом диалоге интерфейс закрывает часть экрана: окно реплики и кнопки внизу примерно от y = 110, а во время торга справа ещё панель цены (на экране примерно x от 215 до 315 и y от 55 до 175). Значения приблизительные и зависят от размера окна. Важные детали сцены лучше держать вне этих зон.
- Квадратики остатка товара (временная отметка «одна штука — один квадрат») пока рисуются поверх фона начиная с x = 330, y = 95. Если настоящие товары нарисованы на фоне и показывают остаток сами, сообщите: отметки отключаются одной настройкой (`ART.stockMarks.show` в `data.js`). Если прилавок в картинке расположен иначе, сообщите координаты, и отметки сдвинем.

## 3. Андрей

| | |
|---|---|
| Ходьба | `assets/characters/andrey_walk.png`, 768×80: восемь ячеек 96×80 подряд в один горизонтальный ряд, слева направо |
| Покой | `assets/characters/andrey_idle.png`, 96×80: одна ячейка |
| Прозрачность | фон ячеек прозрачный |
| Направление | во всех кадрах Андрей смотрит вправо; влево игра зеркалирует кадр |

Для работы нужны оба файла сразу. Если нет хотя бы одного, Андрей остаётся заглушкой целиком.

**Привязка внутри ячейки.** Строки и столбцы считаются с нуля, от левого верхнего угла ячейки.

| Что | Требование |
|---|---|
| Центр опоры по горизонтали | граница между столбцами 47 и 48 (линия x = 48). Центр между стопами в стойке должен лежать на этой границе. Зеркалирование отражает кадр именно относительно неё, поэтому симметричная фигура не сдвигается |
| Линия пола | граница между строками 75 и 76 (линия y = 76). Нижний ряд пикселей подошвы опорной ноги лежит в строке 75 |
| Строки 76–79 | пустые (прозрачные) |
| Рост | около 68 пикселей: строки с 8 по 75 включительно. Допуск 64–72 (по `docs/ANIMATION_SPEC.md`) |
| Выход за ячейку | ничего не должно выходить за границы 96×80 |
| Размер фигуры по ширине | держать внутри ячейки с запасом для маха рук и шага |

Игра ставит ячейку так, чтобы линия пола проходила по линии пола лавки (y = 151), а линия x = 48 была на позиции Андрея.

**Требования к ходьбе**
- 8 разных рисунков в одном ряду. Цикл замкнут: после восьмого кадра снова идёт первый, переход должен быть плавным.
- Каждый кадр цельный рисунок; не собирать ходьбу вращением отдельных частей тела.
- Критерии из `docs/ANIMATION_SPEC.md`: руки качаются противоположно ногам, опорное колено мягко сгибается при принятии веса, нет маршировки и скольжения, лицо, одежда и пропорции одинаковы во всех кадрах.
- Для сравнения: сейчас скорость ходьбы 47 пикселей в секунду, а длина полного цикла (все 8 кадров) временно 40 пикселей. Это даёт около 0,85 секунды на цикл, то есть примерно 9 рисунков в секунду. Это формат первого теста, а не выполнение прежней цели в 20 уникальных рисунков в секунду.

**Что нужно от Кирилла для настройки ходьбы**
- Сколько пикселей должен проходить Андрей за один полный цикл из 8 кадров (два шага), чтобы стопы не скользили. Число подставляется в `ANDREY.cycleDistance` в `data.js`.
- Нужны ли отдельные кадры для ходьбы влево (если одежда или предметы несимметричны). Пока игра просто зеркалит.

## 4. Что пока не подключено

Мать, покупатели (Павел, Дарья) и портреты в диалогах остаются временными заглушками. Форматы для них определим отдельной итерацией; новый внешний вид для них код не создаёт.

## 5. Как проверить свои файлы перед отправкой

1. Проверить имена и размеры: правая кнопка по файлу → «Свойства» → «Подробно» (ширина и высота в пикселях).
2. Положить файлы в нужные папки распакованной копии репозитория (не открывать игру из архива) и открыть `index.html`.
3. Если надпись «Временная графика» исчезла, все обязательные файлы приняты. Если осталась, открыть F12 → Console: там написано, какой файл не найден или какого размера он должен быть.
4. Пройти по лавке туда и обратно: стопы не должны проваливаться ниже линии пола или парить над ней, на остановке должен показываться кадр покоя, при развороте фигура должна оставаться на месте.
