# Летописи 1812: состояние проекта

Обновлено: 20.10.2026. Файл ведёт Ваня; перед правкой договариваемся, кто редактирует (один файл — один редактор).

## Как запустить

1. Скачать репозиторий целиком (Code → Download ZIP) и **распаковать в новую пустую папку** (не открывать игру из архива). `index.html` и `data.js` должны лежать рядом.
2. Дважды щёлкнуть `index.html`. Установка и сервер не нужны.
3. Управление: стрелки или A/D — ходьба (только влево-вправо), E — говорить или осматривать прилавок, N — заметки. «Новая игра» (слева вверху) сбрасывает всё.

Если вместо игры показано сообщение «Игра не может запуститься», рядом с `index.html` нет подходящего `data.js`. Если в углу написано «Временная графика», не хватает каких-то файлов графики: подробности в консоли браузера (F12 → Console).

## Известные проблемы
- Чёрный экран с двумя наложенными кнопками значит, что рядом с `index.html` нет `data.js` или лежит его старая версия (бывает при дублях вроде `data (1).js`). Теперь игра в таком случае пишет понятное сообщение; номер версии данных в `data.js` (`DATA_VERSION`) должен совпадать с проверкой в `index.html` (сейчас 7).
- 20.10.2026 с 22:42 до 23:04 в репозитории лежала несовместимая пара файлов (старый `index.html` и новый `data.js`), потом был короткий период без `index.html`. Рабочая сборка в репозитории с 23:04, с проверкой версии данных с 23:16.
- Дубли «(1)» появляются, когда браузер скачивает файл с именем, которое уже есть в папке загрузок. Перед загрузкой в репозиторий проверять имена: никаких «(1)» быть не должно. Лучше удалять старые копии перед новым скачиванием или загружать через GitHub Desktop.

## Устройство сборки
- `index.html` — движок: сцена, слои, камера, ходьба, диалоги, торговля, заметки, сохранение в браузере (ключ `letopisi1812_save_v6`), загрузка графики с проверкой размеров. Содержимого не хранит.
- `data.js` — всё содержимое и настройки (первой строкой `DATA_VERSION`): `ART` (пути и параметры графики окружения), `ANDREY`, `SCENE`, `GOODS`, `CUSTOMERS`, `NODES` (реплики), `RUMORS`, `CONTEXT`, `PROMISES`, `MOTHER`.
- Слои (снизу вверх): фон помещения и объекты позади персонажей, отметки остатка товара, персонажи, передний план, интерфейс (HTML поверх сцены).
- Графика необязательна: каждый файл можно не класть. Нет файла или неверный размер: рисуется заглушка, в углу короткая надпись «Временная графика», подробности в консоли. Фон подключён: старые окна, полки, прилавок, свеча и ковёр из прямоугольников не рисуются. Передний-план-заглушка рисуется только вместе с заглушкой фона.
- Андрей использует спрайты только если есть оба файла (ходьба и покой), иначе заглушка целиком.
- Торговля одним правилом без случайности: согласие, если цена за единицу не выше предела, сумма в бюджете и товар есть; иначе встречная цена; после третьей неудачной попытки покупатель уходит. Деньги и товар меняются в одном месте и один раз. Открытие торга только показывает панель, цена отправляется отдельной кнопкой.
- Слух записывается один раз (тема, сообщение, кто сообщил, источник, тип) и остаётся при отказе от покупки. Мать только дополняет запись. Просьба Павла сохраняется как обещание; выполнения пока нет.
