# Летописи 1812

Историческая 2D-RPG о молодом лавочнике Андрее: семейное дело, торговля, разговоры и решения в эпоху 1812 года. «Лавка» — рабочее название первого игрового эпизода.

## Состояние

Репозиторий только создан. Игровая сборка пока не загружена; запустить игру из этого репозитория ещё нельзя. Существуют отдельные браузерные прототипы. Пиксельный визуальный стиль находится на стадии проб; готового утверждённого пиксельного цикла ходьбы пока нет.

## Работа команды

- Кирилл: направление игры, сюжет, историческое содержание и утверждение визуала.
- Ваня: техническая реализация, структура проекта, подключение ресурсов и проверка сборок.
- Помощники ИИ предлагают и готовят изменения; участники проверяют результат в игре.

На старте работаем в основной ветке. Перед работой в GitHub Desktop: Fetch origin → Pull origin, если есть изменения. После законченной задачи: просмотреть Changes → Commit → Push origin. Коммит сохраняет историю, Push передаёт изменения команде. При конфликте не перезаписывать чужую работу.

Код ведёт Ваня. Кирилл добавляет утверждённые изображения в assets/ и согласует тексты отдельно. Один файл одновременно редактирует один участник.

## План структуры

- index.html — точка входа; добавляет Ваня вместе с рабочей сборкой.
- data.js — товары, покупатели и реплики; отделяет от логики Ваня, затем согласуем формат и владельца данных.
- assets/characters/ — утверждённые спрайты.
- assets/backgrounds/ — утверждённые фоны.
- docs/ — решения и требования.
- legacy/ — при необходимости архив прежнего рисованного прототипа.

Названия файлов — латиницей, без пробелов. Пример: andrey_walk.png. Не загружаем пароли, ключи API, node_modules и временные файлы.

## Ближайшая итерация

1. Ваня загружает текущую рабочую сборку и указывает способ запуска.
2. Подготавливает сцену 320×180 с настраиваемой загрузкой листа кадров и временной заглушкой.
3. Кирилл утверждает отдельный пиксельный спрайт Андрея и тест ходьбы.
4. Подключаем спрайт, проверяем движение, остановку, разворот, опору стоп и камеру.

Параметры графики: [docs/ANIMATION_SPEC.md](docs/ANIMATION_SPEC.md).

Мать подтверждена как персонаж. Полноценная торговля, движение NPC, сюжетные последствия и концовки — планы, а не готовые возможности этой сборки.
