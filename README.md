# Летописи 1812

Историческая 2D-RPG о молодом лавочнике Андрее: семейное дело, торговля, разговоры и решения в эпоху 1812 года. «Лавка» — рабочее название первого игрового эпизода.

## Состояние

Игра начинается **1 июня 1812 года по старому стилю** (подтверждено Кириллом). В браузерной сборке играется **первая неделя, 1–7 июня**: семейная лавка в Китай-городе, мать, покупатели Павел, Дарья и Фёдор (приходят по нескольку раз и помнят прошлый приход), торг за прилавком, бытовой слух с проверкой источников, обещание, закупка крупы у купца Сорокина в лабазе (переход через карту) с доставкой на следующее утро, итоги дня и смена дней. Дальше до 2 сентября расставлены главы и даты, но покупателей и событий в них пока нет. Цены, количества и реплики тестовые.

Графика: фон лавки, Андрей (покой и ходьба в 4 кадра), мать в сцене. Покупатели, Сорокин, лабаз и портреты пока заглушки. Что именно сделано, проверено и чего нет: [PROJECT_STATE.md](PROJECT_STATE.md).

## Как запустить

1. Скачать репозиторий (Code → Download ZIP) и **распаковать в новую пустую папку** (правая кнопка → «Извлечь всё»). Не открывать игру из архива: так `data.js` не загрузится. Файлы `index.html` и `data.js` должны лежать рядом.
2. Дважды щёлкнуть `index.html`. Установка и сервер не нужны.
3. Управление: стрелки или A/D — ходьба, E — поговорить с матерью или у рабочего места справа: утром открыть лавку, днём встать за прилавок, вечером закончить день, N — заметки, M — карта (там же переход в другие места: выбрать место → «Отправиться»), Esc или кнопка «Отойти от прилавка» — выйти из обслуживания. «Новая игра» (слева вверху) сбрасывает всё.

Если вместо игры показано сообщение «Игра не может запуститься», рядом с `index.html` нет подходящего `data.js`: скачайте репозиторий целиком (Code → Download ZIP), распакуйте в новую пустую папку и откройте `index.html` оттуда.

Если в углу надпись «Временная графика», это нормально: часть картинок (покупатели, Сорокин, лабаз, портреты) ещё не передана. Какого файла не хватает, видно в консоли браузера (F12 → Console).

Точные требования к изображениям (имена, размеры, точка опоры Андрея, слои): [docs/ART_REQUIREMENTS.md](docs/ART_REQUIREMENTS.md).

## Работа команды

- Кирилл: направление игры, сюжет, историческое содержание и утверждение визуала.
- Ваня: техническая реализация, структура проекта, подключение ресурсов и проверка сборок.
- Помощники ИИ предлагают и готовят изменения; участники проверяют результат в игре.

**Ветки.** `main` — согласованная рабочая сборка, в неё напрямую не загружаем. Все тестовые обновления идут в ветку `test`. Когда обновление согласовано с Кириллом и доработано, его переносят из `test` в `main` через Pull request (Pull requests → New pull request → base: `main`, compare: `test` → Merge). Так рабочая сборка не ломается случайно.

Скачать тестовую сборку: на странице репозитория переключить ветку на `test` (кнопка с названием ветки слева вверху) → Code → Download ZIP. В GitHub Desktop: Current branch → `test`. Загружая файлы через сайт («Add files via upload»), сначала переключитесь на ветку `test`.

Перед работой в GitHub Desktop: Fetch origin → Pull origin, если есть изменения. После законченной задачи: просмотреть Changes → Commit → Push origin. Коммит сохраняет историю, Push передаёт изменения команде. При конфликте не перезаписывать чужую работу.

Код ведёт Ваня. Кирилл добавляет утверждённые изображения в assets/ и согласует тексты отдельно. Один файл одновременно редактирует один участник.

## Структура

- index.html — движок (сцена, камера, диалоги, торговля, заметки, сохранение). Содержимого не хранит.
- data.js — всё содержимое и настройки: сцена, товары, покупатели, реплики, слухи, обещания, параметры спрайта и пути графики (блок `ART`). Первая строка — `DATA_VERSION`, он должен совпадать с проверкой в index.html. Реплики и числа правятся здесь, без изменения index.html.
- PROJECT_STATE.md — что утверждено, что сделано, что проверено, что открыто.
- assets/characters/ — фигуры в сцене: Андрей (`andrey_idle.png`, ходьба `andrey_walk.png`), мать (`mother_idle.png`); покупатели и Сорокин позже.
- assets/backgrounds/ — фон `shop.png`, слой прилавка `shop_counter.png`, передние ящики `shop_front.png`; фон лабаза `labaz.png` позже.
- assets/portraits/ — портреты для диалога (`pavel.png`, `darya.png`, `fedor.png`, `mother.png`, `sorokin.png`, 120×136), пока не переданы.
- assets/goods/ — необязательные значки товаров 24×24.
- assets/source/ — оригиналы присланных исходников (игра их не загружает).
- tools/ — вспомогательные скрипты для команды (`make_shop_front.py` — слой передних ящиков из фона, `make_sprites.py` — спрайты из крупных генераций); игре не нужны.
- docs/ — решения и требования (`ANIMATION_SPEC.md`, `ART_REQUIREMENTS.md`), планы (`REPUTATION_PLAN.md` — репутация, черновик), промты для ChatGPT (`GPT_PROMPTS.md` — персонажи в стиле Андрея, ходьба в 4 кадра).

Названия файлов — латиницей, без пробелов. Пример: andrey_walk.png. Не загружаем пароли, ключи API, node_modules и временные файлы.

## Ближайшая итерация

1. Кирилл и Ваня проходят первую неделю (1–7 июня) и оценивают реплики, ритм и цены.
2. Кирилл присылает фигуры Павла, Дарьи, Фёдора, Сорокина и портреты (промты — `docs/GPT_PROMPTS.md`); оценивает ходьбу Андрея и мать.
3. Содержание главы 2 (24–30 июня): первые вести о войне.

Параметры графики: [docs/ANIMATION_SPEC.md](docs/ANIMATION_SPEC.md) и [docs/ART_REQUIREMENTS.md](docs/ART_REQUIREMENTS.md).

Мать подтверждена как персонаж (роль в сюжете); её внешность ещё не утверждена окончательно. Смена товара и количества в торговле, движение матери, репутация, сюжетные последствия и концовки — планы, а не готовые возможности этой сборки.
