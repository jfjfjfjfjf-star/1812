# Проверки

Запускать из папки проекта.

| Файл | Что проверяет | Как запустить |
|---|---|---|
| `shop_hd.test.js` | Игра открывается без ошибок; HD-слои лавки (день и ночь) загружены и нужного размера; утром и днём дневной фон, вечером ночной; с `?hd=0` прежние пиксельные слои; Андрей встаёт за прилавок | `node tests/shop_hd.test.js` (нужен Playwright: `npm i playwright`, `npx playwright install chromium`) |
| `check_night_alignment.py` | Ночной исходник лавки совпадает с дневным: предметы не «прыгают» при смене дня и ночи | `python tests/check_night_alignment.py` (нужны numpy и Pillow) |

Обе проверки пишут по строке на каждый пункт («ок» или «ОШИБКА») и завершаются с кодом 1, если что-то не прошло.
