# Проверки

Запускать из папки проекта.

| Файл | Что проверяет | Как запустить |
|---|---|---|
| `shop_hd.test.js` | Игра открывается без ошибок; HD-слои лавки (день и ночь) загружены и нужного размера; утром и днём дневной фон, вечером ночной; на персонажей ложится свет (общий тон по времени суток, свеча, окно); с `?hd=0` прежние пиксельные слои; Андрей встаёт за прилавок | `node tests/shop_hd.test.js` (нужен Playwright: `npm i playwright`, `npx playwright install chromium`) |
| `week.test.js` | Прохождение недели 1–7 июня тремя стилями (честный, жадный, небрежный) через клавиши и кнопки: дни доходят до итогов, ночь сменяется утром, лабаз и заказ у Сорокина, обещание Павлу, торг после «отойти от прилавка», перезагрузка посреди сделки, ошибок нет. В конце — таблица денег по дням, скриншоты в `tests/out/week` | `node tests/week.test.js` (около 2 минут; `--full` — честный стиль доигрывает до финала) |
| `npc.test.js` | Типовые NPC: файлы загружены, у Павла, Дарьи, Фёдора фигуры, люди на случайных местах в лавке (по дню одни, по дням разные, у прилавка свободно; к войне меньше, мужики уходят в ополчение, молва ± люди) и extras в лабазе, прохожие за окном из NPC, ошибок нет; снимки в `tools/out/npc_*.png` | `node tests/npc.test.js` |
| `npc_shots.js` | Снимки NPC на локациях: лавка и лабаз × утро/день/вечер × камера слева/центр/справа, плюс сводный лист `tools/out/npc_shots/npc_shots.png` и лавка днём в дни 1–3 и в начале каждой главы (`shop_days.png`); ошибок страницы нет | `node tests/npc_shots.js` |
| `check_night_alignment.py` | Ночной исходник лавки совпадает с дневным: предметы не «прыгают» при смене дня и ночи | `python tests/check_night_alignment.py` (нужны numpy и Pillow) |

Обе проверки пишут по строке на каждый пункт («ок» или «ОШИБКА») и завершаются с кодом 1, если что-то не прошло.
